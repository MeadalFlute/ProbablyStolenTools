## 实现

### 双编译目标

`ProbablyStolenTools.csproj` 默认 GameRuntime=Mono、netstandard2.1，引用正式版 Managed。原来的 MelonLoader/IL2CPP 引用只在 GameRuntime=Il2Cpp 时使用，Demo 安装保持原 0.5.2 DLL。正式版 IMod 生命周期不重复 PatchAll，因为游戏加载器已负责安装。

### 托管快照

`ManagedStateAccess.cs` 实现原 IStateAccess / StateGraph 接口：捕获真实字段与数组元素，结构体内有引用时逐层展开字段路径，恢复时写回装箱后的结构体，再写回其拥有者。对象身份来自弱引用表的单调 ID，快照期间以强引用持有原对象；ID 从来不是可移动托管堆的地址。

保留循环与共享引用、泛型集合原始数组、原对象身份、多个节点前后往返、随机源、只跟踪字段白名单的根对象。委托本身不重建、不覆盖函数指针，遍历每个 invocation target 以捕获闭包业务状态。Nullable 标量按值保存；含引用的 Nullable 结构体拒绝捕获。未知可变类型、指针和越界数组继续拒绝捕获，不返回半份快照。

浮点值的比较 token 按位区分符号零及 NaN 表示。恢复使用 FieldInfo.SetValue / Array.SetValue，交由 GC 处理引用写屏障。Unity.Random.state 使用公开托管 API；MonoBehaviour 使用正常 AddComponent，不使用 IL2CPP 注入构造器。

`GameFields.cs` 对旧代理暴露、正式版隐藏的字段显式访问；保留属性回退供 IL2CPP 代理使用，不 publicize 或改写游戏程序集。原始业务图的同日/同店/同场景边界不放宽。

### 正式版 UI

保留游戏原生 CustomUIManager 窗口、设置、拖动、缩放和坐标持久化。

交易详情已重写：旧的 UpdateItemFeatureGroup 与 itemFeatureUIs 不存在，水质挂到 BuildExpandedRow 的 postfix，查找 `uiObject` 下的实际 ItemFeatureUI。它们不在 NegociationUIManager 本体的 Transform 下，因此不能对管理器直接 GetComponentsInChildren。原生 ItemFeatureUI.Awake 会绑定 TMP。

议价业务字段仍存在，恢复后的控件刷新使用公开 RefreshUI()，与正式版 Update 调用同一路径。TreeNodeRender.parent 私有 setter 与顾客 SetSolidBlend 通过明确成员访问恢复视图。

### 配置与存档

新配置位于共享 persistentDataPath 下 `PSTools.settings.xml`。即时持久化使用临时文件替换、保留 `.bak`；文化区域固定为 invariant，未知配置项保留。现有 Demo TOML 通过实际 Tomlet 解析器迁移，仅复制自研配置，三个 Debug 自动化开关强制关闭；已有正式版 XML 时不覆盖。

已迁移 28 个设置项，包含自动报价/提交、对话快进、鉴定摘要/双击、窗口位置/尺寸/折叠与原热键。第三方 Inspector 项未迁移。

正式版与 Demo 共用存档目录。部署没有启动游戏、调用 SaveGame、改 ES3、切槽或覆盖 backup_save。F7 保留原来的用户主动恢复流程与 `.pre_restore`。原 Inspector 为 IL2CPP 构建，不能直接复制到 Mono 正式版。

## 验证

- Mono 与 IL2CPP Release 均编译 0 警告、0 错误。
- CheckpointTests：48 项通过；包含 10 项新增托管后端测试：压缩 GC 后身份、循环共享引用、集合扩容删除、含引用结构体、多播闭包、随机序列、根白名单、前后节点往返、dispose、防空值与符号零。
- ReleaseCompatibility：实际 DLL 上 51 个 Harmony 入口及注入参数名/类型唯一匹配；68 个快照及私有字段存在。
- 实际官方 ModScanner：HardFlags 为空、Error 为空，检测到 `files, reflection-external`，manifest 声明匹配。无需声明 network/process/native/dynamic-code。
- 实际正式版 ModConfig 磁盘往返：开启即时保存，在 de-DE 文化下写入小数，重读布尔/坐标保持正确，替换保留 `.bak`。
- 实际正式版 PlayerStore/StoreStation/GameItemElement 类型：跳过游戏构造器，仅离线创建数据对象，捕获、修改、恢复后现金/日期/物品引用一致、Differences=0。
- 真实 save_0.es3 只读元数据检查通过。此时 day=64、cash=1309、state=2、slot=0，此值仅为当次读取结果，不应作为后续断言。

离线数据测试运行在 .NET 测试进程，不是 Unity 自带 Mono。没有测试真实进程内补丁安装、完整活体业务图、原生渲染/命中/场景切换。不得据此称完整游戏验收通过。

## 部署

初始源码、测试、共享存档和 Demo 配置备份：`out\full-release-20261028-235105`。

正式部署备份：`out\full-release-deploy-20261029-001459`，包含 SaveData、原正式版 Mods、导入配置预览及 deployment.json。123 个原存档目录文件在备份和部署后逐一 SHA256 一致；原游戏 Managed 文件逐一哈希不变。新增独立 XML 不覆盖旧文件。部署 DLL 与构建输出哈希一致。

`scripts\Deploy-FullRelease.ps1` 可重用：检查 Mono 目标、按 EXE 完整路径关闭目标游戏、备份并校验、复制 DLL/manifest、仅在 XML 不存在时迁移、记录部署结果，不启动游戏。脚本验证不修改原生 Mod 信任/启用记录。

## 用户验收

1. 启动正式版，在 Mod 列表启用 Probably Stolen Tools 0.6.0，确认声明能力，按游戏提示重启。
2. 载入存档，F8 检查原生窗框、中文、设置、拖动/缩放/收起和重启位置。
3. 普通顾客开场结束后出现节点；交易、议价或使用试纸后 F6，检查物品/现金/贴图与再次议价，检查录音机。双击历史和后续节点，等新顾客出现再检查分支截断。
4. 测水质标签、双击放大镜、鉴定报价和摘要开关，关页确认没有窗口残留。
5. 闭店保留同日节点；离店/跨日释放。F7 为会写回当前槽位的主动验收，明确按键后才执行。
