# 快速重载存档与重掷随机数

## 行为

设置面板新增两个操作按钮，不是持续生效的开关：

- 快速重载存档：读取当前周目、当前槽位的原版磁盘存档，不使用内存晨间锚点，不主动调用 SaveGame，不覆盖活动档。沿用既有安全暂存/LoadGate 验证和主菜单自动载入流程，强制 menu，不受旧 RestoreMode 配置影响。未保存进度与所有旧内存节点会失效，默认沿用 ConfirmWholeDayRewind 确认；无法显示确认 UI 时拒绝，不擅自直接重载。
- 重掷随机数：给游戏 RNG.random 与 UnityEngine.Random 重新设种子，只影响后续随机计算。不重建已经生成的顾客/物品，不读写存档、不自动读档、不改变 F5/F7 或普通节点精确恢复随机状态的规则。恢复旧节点仍恢复该节点的 RNG，之后可再手动重掷。
- 不保证每次结果必然不同：已缓存/预生成结果不变，新随机序列也可能再次抽中相同结果。

快捷键默认均为 KeyCode.None；设置页改键沿用键盘/鼠标中键/侧键、冲突交换、清空与恢复默认的既有机制。

```xml
<Entry key="Rewind.KeyQuickReload" value="None" />
<Entry key="Rewind.KeyRerollRandom" value="None" />
```

这些键由配置初始化正常补入，无须玩家手工添加。仅需按钮时保持 None。

## 安全边界

共用 CustomerCheckpoint.SaveActionBlocker：菜单、无商店/UI、读档/回溯/确认未结束、原版解码、
夜间/报告/黑屏/游戏结束/漏斗传输、店外/输入文字/射击/逮捕、闭店/交易/延时回调、
拖拽/群选/顾客移动/通话/对话等阶段拒绝；确认完成后再次检查。

快速重载只读精确 save_{slot}.es3，绝不使用“最近其他槽位”回退。解析失败、槽位/周目不一致、
营业中或未知状态拒绝并显示具体异常；允许磁盘日与内存不同（例如此前已回到昨天）。
真正读档验证前不提前清空旧节点；沿用原有成功载入后的身份失效与清理。
普通原生读档完成后，不运行检查点专用的队列重建、送客/清顾客和卷帘门修补。

重掷先保存两套随机源，初始化失败尝试回滚；不先从游戏随机源取种子，避免额外消耗旧随机序列。
重掷成功后 0.5 秒内重复请求忽略，按钮/快捷键共用。成功/拒绝/失败记录保留，失败提示包含异常类型/消息。

本轮同时修复连续文件回退：上一轮读档的 20 秒诊断尾部尚未结束时，新 PendingPoint 必须覆盖旧 resumePoint，
否则新一轮可能被旧阶段标记跳过。新 load gate 优先，不降低载入日期/槽位/周目校验。

## 验证

- 主 DLL Release 构建 0 警告/0 错误。
- 430 项参考测试通过，设置布局覆盖两按钮与 12 个快捷键、化学分割线、多宽度滚动边界。
- tests/GameSaveActionTests 直接编译生产 GameSaveActions + SaveMetadata，13 项通过：确认分派、
  阻塞请求、缺档不跨槽回退、正确元数据/强制 menu、晨间/闭店、错槽位/周目、
  营业/未知状态/坏档拒绝、确认后重新门控、双随机源重设/节流/部分失败回滚与存档字节不变。
- ReleaseCompatibility 的实际 DLL API/能力扫描通过，仍只检测 files，HardFlags/Error 为空。
- 原版 Unity.Random 原生调用与真实场景重载必须实机验收；测试桩不冒充 Unity 活体验证。

## 验收

1. 设置页两个操作按钮可见，两条快捷键显示未绑定；分别绑定键盘/鼠标侧键，重启保持，恢复默认清空。
2. 快速重载弹出进度/节点丢失警告；取消不改变游戏。确认后回到磁盘保存日期/进度，旧内存节点失效。
3. 连续两次快速重载、一次普通文件回退后再快速重载，不停留在旧载入收尾状态；存档文件不被 Mod 改写。
4. 在尚未确定结果的同一个后续随机操作前建点，反复回溯应保留原结果；回溯后手动重掷，多次试验验证随机序列可变化。已有顾客/物品不应被突然替换；不要求单次抽签一定不同。
5. 打字/改键/对话/拖拽/夜间结算/载入中不触发；读档/设置错误提示具体原因。
