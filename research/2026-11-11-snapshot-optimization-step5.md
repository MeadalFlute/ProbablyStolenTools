# 第五步：恢复前只读对象普查

## 改动

恢复前的 current 原本完整捕获，但只用于枚举新增物品/窗口，没有用于失败回滚。本轮改为 Census：与 Capture 共用 BFS、根注册、描述、引用发现、来源路径、预算和 Validate；所有标量仍实际读取，Mono 不登记值令牌，也不保存 Entry。其他访问器回退 ReadValue 并按实际字节长度计预算。

普查被明确标记为不可恢复，Restore/Differences 一律拒绝，不能作为空的有效节点。正常节点 Capture 不变；目标完整读取预检、每次完整校验、原生视觉/几何/最终变换顺序和校验成功后清理均保留。普查失败仍整份释放，写入后失败仍要求重新加载，不声称具备回滚能力。

## 验证

- 103 项离线回归；新增六项：图覆盖/来源与数值预算对照、无令牌/Entry、误用防护、逐字段失败、通用读取与 Validate 失败、预算一致及选定根。
- 真实安装版 PlayerStore/StoreStation/GameItemElement 数据图比较：普查与捕获对象、路径、计数一致；无多余值令牌，旧节点恢复仍通过。仅构造无原生回调的测试对象，不运行游戏或保存 API。
- Release 0 警告 / 0 错误，55 挂点 / 73 字段检查和官方扫描通过，HardFlags 为空。
