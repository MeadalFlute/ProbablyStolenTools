# 0.5.2：游戏原生 UI 与启动耗时调查

日期：2026-10-23。

## 调查结论

第三方 ProbablyStolenInspector 3.24.3 使用游戏自身的 `CustomUIManager`、`CustomUIBuilder`、`CustomUIWindow` 和 `CustomUIWindowFrame`。窗框、标题、按钮、标签、复选框均可通过游戏公开的 mod UI API 创建；无须引用、修改或拷贝第三方插件的业务代码。

本地证据：

- `out\inspector-ui-reference-20261023\ProbablyStolenInspector\InspectorMod.cs`，`BuildAuthenticityWindow` 约第 597 行。
- `decompiled\CustomUIManager.cs`、`CustomUIBuilder.cs`、`CustomUIWindow.cs`、`CustomUIWindowFrame.cs`。
- `cpp2il_isil\IsilDump\Assembly-CSharp\CustomUIBuilder.txt` 和 `UIDragHandler.txt`，用于确认布局和拖动行为。游戏 dummy 方法体为 throw null，不是实际实现证据。

## UI 改造

- `NativeUi.cs`：统一创建原生 overlay 窗口、固定尺寸、按参考区域左上角布局和顶层射线命中；原生拖动可能切换到 letterbox dock，位置通过世界坐标转换处理，不假设窗口始终在同一父级。
- `QuickInspectionPatch.cs`：原生标题与窗框，原生可滚动正文；300×240 尺寸、归一化位置、即时开关与页面生命周期继续沿用。移动边界改为 overlay，而非原鉴定页矩形。字体或内容变化后重新计算原生标签的布局高度。
- `Panel.cs`：原生回溯窗框、节点按钮、设置复选框和文字；保留 F8、列表双击、四列、缩放、收起和配置。设置区滚动，固定行高；原生委托显式保活。小型回溯 toast 保留独立 Canvas，不抢焦点。
- 节点按钮禁用原 TMP 组件而不是禁用其 GameObject，避免预制体结构变化导致整行消失。手动布局的内容禁用局部自动 Layout，不破坏原生窗框自身布局。
- 关页、失活、场景或管理器变化时释放原生窗口及引用；未改任何鉴定业务、节点捕获、恢复和安全边界。

## MelonLoader 启动慢

本次定位的是当前安装的重复生成问题，不是对两个框架进行完整性能评测。

游戏 `MelonLoader\Latest.log`：

- `00:00:30.718`：Assembly Generation Needed!
- `00:00:48.987`：Interop Generation Complete!
- 两者相隔约 18.27 秒，耗时集中在 Cpp2IL 与 IL2CPP 代理生成，发生于加载 Mods 之前。

当前状态：

- `UserData\Loader.cfg`：`force_offline_generation=true`、`force_regeneration=false`。
- 缺少 `MelonLoader\Dependencies\Il2CppAssemblyGenerator\Cpp2IL\Plugins\Cpp2IL.Plugin.StrippedCodeRegSupport.dll`。
- 缓存记录的 GameAssembly 哈希与实际一致，不能把重复生成归因于游戏更新。

从本机生成器 DLL 反编译得到的链路：

1. `Cpp2IL_StrippedCodeRegSupport.ShouldSetup()` 发现目标文件缺失，返回 true。
2. `PackageBase.Setup()` 将 `Core.AssemblyGenerationNeeded` 置 true。
3. 离线模式跳过下载，缺失文件仍不会补齐。
4. 此包 `FilePath == Destination`；`FileHandler.Process()` 对同路径直接返回 true，早于文件存在检查。
5. Setup 保存版本信息，但下一次仍因文件缺失重新触发。即使 GameAssembly 哈希一致，也不会清除已经置位的重建标记。

反编译位置：`out\assembly-generator-reference-20261023`，分别见 Packages、Packages.Models 和主命名空间目录中的相应 .cs 文件。

**本轮没有修改加载器、恢复缺失插件或关闭离线模式。** 此前迁移有黑屏与移除插件的历史，需另行查看 `out\Cpp2IL-probe-20261022` 和 `out\Cpp2IL-no-plugin-generation-20261022` 后验证。不能声称启动耗时已改善。
